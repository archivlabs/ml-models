# ml-models

Distribution hub for ML models.

This repository hosts model files that Archiv Co., Ltd.'s applications download for over-the-air model updates.

The repository is publicly accessible solely to enable these downloads. **It is not an open-source project.**

## Layout

    <model>/manifest.json    # Latest version, download URL, and SHA-256 checksum

Model files are attached to GitHub Releases tagged `<model>-<version>` (e.g., `segmentation-v11-ep15`).
